# Muhammed Yousuf — Academic Research Site

A premium, dark-first academic website for an Environmental Engineering and Atmospheric Science PhD researcher at IIT Delhi.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion · React Three Fiber · Lucide

## Personalisation

All editorial content is intentionally centralised in `components/research-site.tsx`. Replace the placeholder publication titles, projects, profile links, email address, and research-history details with Muhammed's verified information before publishing.

## Publish to GitHub

Create an empty GitHub repository, then run:

```bash
git init
git add .
git commit -m "Create premium academic research site"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```
